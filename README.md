# Search Auto

Search Auto là extension hỗ trợ tự động hoá các lượt tìm kiếm Bing và theo dõi tiến trình Microsoft Rewards.

## Tải từ GitHub

1. Mở trang GitHub của dự án.
2. Chọn **Code** → **Download ZIP**.
3. Giải nén file ZIP vào một thư mục cố định trên máy, ví dụ `C:\Extensions\Search-Auto`.

> Không xoá hoặc di chuyển thư mục này sau khi cài: trình duyệt chạy extension trực tiếp từ đây.

## Cài trên Microsoft Edge

1. Mở Edge và truy cập `edge://extensions`.
2. Bật **Developer mode** ở thanh bên trái.
3. Chọn **Load unpacked**.
4. Chọn thư mục đã giải nén — chính là thư mục chứa file `manifest.json`.
5. Extension **Search Auto** sẽ xuất hiện trong danh sách. Nhấn biểu tượng mảnh ghép trên thanh công cụ và ghim extension nếu cần.

## Cài trên Google Chrome

1. Mở Chrome và truy cập `chrome://extensions`.
2. Bật **Developer mode** ở góc trên bên phải.
3. Chọn **Load unpacked**.
4. Chọn thư mục đã giải nén chứa `manifest.json`.
5. Ghim biểu tượng Search Auto vào thanh công cụ để dễ mở.

## Bắt đầu sử dụng

1. Đăng nhập tài khoản Microsoft của bạn trên Bing.
2. Nhấn biểu tượng Search Auto để mở bảng điều khiển.
3. Thiết lập số lượt tìm kiếm, chế độ chạy và lịch chạy theo nhu cầu.
4. Nhấn nút bắt đầu và giữ trình duyệt mở trong lúc extension hoạt động.

## Cập nhật phiên bản mới

1. Tải và giải nén phiên bản mới từ GitHub vào thư mục cài đặt.
2. Mở lại trang extension (`edge://extensions` hoặc `chrome://extensions`).
3. Nhấn nút làm mới trên thẻ Search Auto.

Nếu bạn đổi sang thư mục cài đặt mới, hãy dùng **Load unpacked** để chọn lại thư mục đó.

## Khắc phục lỗi thường gặp

- **Không thể chọn thư mục:** hãy chọn đúng thư mục có file `manifest.json`, không chọn riêng file ZIP.
- **Extension không hiện biểu tượng:** mở menu mảnh ghép (Extensions) rồi ghim Search Auto.
- **Extension không chạy:** kiểm tra bạn đã đăng nhập Bing và tải lại extension từ trang Extensions.
- **Báo lỗi sau khi cập nhật:** vào trang Extensions, nhấn nút làm mới của Search Auto rồi mở lại popup.

## Lưu ý

Bạn tự chịu trách nhiệm bảo đảm việc sử dụng extension tuân thủ điều khoản của Microsoft Rewards và các chính sách áp dụng cho tài khoản của mình.
