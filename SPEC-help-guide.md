# Spec: Help Guide

## Objective

Update the Vietnamese user guide so users can understand the new quick-start
popup and find detailed controls in the separate settings tab.

Keep the shared guide and the Firefox-specific guide aligned with their
respective browser labels and limitations.

## Requirements

- Explain how to start a run from the popup and how saved settings affect it.
- Explain how to read progress and stop a run.
- Explain how to open the settings tab and where to find schedules and other
  non-destructive controls.
- Keep installation, account setup, schedule behavior, troubleshooting, and
  existing safety-relevant explanations accurate after the UI changes.
- Keep screenshots or UI-specific labels synchronized if the guide uses them.

## Success Criteria

- A user can follow the guide to start, monitor, stop, and customize a run using
  the refreshed interface.
- The guide does not refer to controls that were removed or moved without
  explaining their new location.

## Boundaries

- Preserve accurate descriptions of current extension behavior; do not imply
  that schedules run while Chrome is closed.

## Open Questions

- None.
